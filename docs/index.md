# Documentation

Проект демонстрирует работу с Git, CI/CD и Python.

## Файлы проекта

- `main.py` – основной скрипт для вывода и сохранения информации о человеке.
- `data.py` – содержит словарь PERSON с информацией о человеке.
- `utils.py` – функции для сохранения и чтения summary файла.
- `feature2.py` – дополнительная функция из ветки dev2.

## CI/CD

Настроен GitHub Actions workflow для автоматического запуска скрипта при каждом коммите.
